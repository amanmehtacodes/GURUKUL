Quick format reminder
Write each description as a single flowing paragraph with a clear introduction, a detailed body covering the relevant points, and a brief conclusion — objective, vivid and systematic, one aspect at a time, with no slang or repetition. Stay close to 80-100 words. See Lesson 5 for the full points lists and four worked examples.
